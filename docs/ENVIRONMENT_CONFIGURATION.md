## Environment Configuration

L'application supporte les variables d'environnement suivantes :

| Variable | Description | Valeur par défaut |
|---|---|---|
| `PORT` | Port d'écoute du serveur HTTP | `3000`[cite: 1, 3] |
| `NODE_ENV` | Environnement d'exécution (`development`, `test`, `production`) | `development`[cite: 3] |

### Utilisation locale
Copier le fichier d'exemple pour initialiser la configuration locale :
```bash
cp .env.example .env
